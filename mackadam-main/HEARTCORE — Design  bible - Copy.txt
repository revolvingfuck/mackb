HEARTCORE — Design Document
1. EXECUTIVE SUMMARY
Item	Description
Title	Heartcore Resonance
Genre	Action-RPG
Platform	TBD
Target Playtime	20-25 hours
Core Mechanic	Dual-layer combat + moral history as physical object
One line: An action-RPG where your moral history is a physical object you carry, growing on your baby golem's body and in a cave, and the ending is read from the pattern, not chosen.

3. COMBAT SYSTEM
3.1 Control Types
Tier	Characters	Control Type
Direct-control	Luto, Corrine	Real-time action. Move, dodge, attack.
Trust-based	Aya, Eli, Gurtohli, Myc	ATB commands. Ally executes.
3.2 ATB Mechanics (Trust-Based Characters)
Stat	Value
Base ATB Fill Time	3.0 seconds
Fastest ATB (max interiority)	1.5 seconds
Slowest ATB (min interiority)	5.0 seconds
Command Response Delay (min interiority)	1.0 second
Command Refusal Threshold (min interiority)	10% chance
3.3 Interiority Stat Impact
Interiority Level	ABS	Effectiveness	Critical	Mana Cost	Responsiveness
0 (Closed)	50%	50%	50%	150%	50%
1	65%	65%	65%	130%	65%
2	80%	80%	80%	110%	80%
3 (Open)	100%	100%	100%	100%	100%
3.4 Luto's Balance System
Balance Value	Paladin Effectiveness	Berserker Effectiveness	Berserker Cost
0 (Alone)	50%	150%	50 Remorse/sec
1	70%	130%	40 Remorse/sec
2	85%	115%	30 Remorse/sec
3 (Held)	100%	100%	20 Remorse/sec
Balance is calculated from party interiority average.

Average interiority 0-1 → Balance 0

Average interiority 2 → Balance 1

Average interiority 3-4 → Balance 2

Average interiority 5+ → Balance 3

Berserker activation cost: 100 Remorse points minimum. Drains 20-50 Remorse/sec.
Paladin activation: Free. Available always.

9. BOSS FIGHTS
9.1 Gannet (Part 1)
Phase	HP	Attacks	Strategy
1	100%	Melee combo, grab, throw	Dodge, wait for opening
2	60%	Summons 2 grunts	Defeat grunts, Gannet staggers
3	30%	Berserk mode, no grunts	Luto must use Paladin shield
9.2 Cormorant (Part 2)
Phase	HP	Attacks	Strategy
1	100%	Torpedo, claw swipe	Stay mobile
2	60%	Submerges, minions summoned	Defeat minions to force surface
3	30%	Surface phase, melee barrage	Block, counter
9.3 Heron (Part 3)
Phase	HP	Attacks	Strategy
1	100%	Tech weapons, lasers	Use Gurtohli's hack to disable
2	60%	Summons 3 clones	Find real Heron (different color)
3	30%	Desperation, all weapons	Guard, heal, survive
9.4 Poliphibious (Part 3/4)
Phase	HP	Attacks	Strategy
1	100%	Underwater: torpedo, tentacle	Use Corrine's scanners to reveal weak point
2	60%	Emerges: melee, bite	Use Eli's ice magic (vulnerability)
3	30%	Enraged: all attacks	Use tribe's knowledge—hit weak point on back
9.5 Alba Clone (Part 3)
Phase	HP	Attacks	Strategy
1	100%	Tech weapons	Standard fight
2	50%	Summons 2 grunts	Defeat grunts first
3	25%	Self-destruct countdown	Finish before timer
9.6 Sons Together (Part 4)
Character	Role	Strategy
Gannet	Tank	Has high DEF, focus after others
Cormorant	Ranged	Interrupt with Gurtohli
Heron	Tech support	Disable with hack
9.7 Alba (Part 4)
Phase	HP	Attacks	Strategy
1	100%	Clones stalk environment	Use unique abilities to navigate
2	70%	True form: tech weapons, melee	Dodge, attack in openings
3	40%	Satellite connection	Must use Myc combo to sever connection
4	20%	Desperation mode	All attacks, no mercy
